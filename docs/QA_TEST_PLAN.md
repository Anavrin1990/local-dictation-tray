# QA test plan — Local Dictation

## Цель

Подтвердить, что Windows tray-приложение надёжно записывает диктовку по удержанию глобальной горячей клавиши, локально распознаёт её через Whisper, вставляет текст в активное поле, а также безопасно хранит историю и диагностические логи.

## Критерии приёмки

| Область | Автоматическая проверка | Ручная/интеграционная проверка |
| --- | --- | --- |
| Запуск | Импорты, конфигурация и создание папок данных без исключений | После установки приложение запускается без консольного окна и появляется в tray |
| Hotkey | Нормализация комбинаций, обработка press/release, защита от повторного старта | Удержание назначенной клавиши начинает запись; отпускание останавливает её; работа в сторонних программах |
| Микрофон | Состояния recorder, корректное завершение пустой/короткой записи, освобождение ресурса | Выбор/запрос разрешения микрофона Windows; отсутствие зависания при отключении устройства |
| Whisper | Запрос локальной модели, обработка ошибок/пустого результата, язык `ru` | Распознавание русской речи без сети после первичной установки модели |
| Вставка | Текст передаётся в слой вставки без потери Unicode | Текст появляется в фокусированном поле (Notepad, браузер, мессенджер); clipboard восстанавливается или используется безопасный ввод |
| История | Добавление, сортировка, лимит, атомарное/защищённое хранение | Окно истории показывает время, текст и ошибки; переживает перезапуск |
| Логи | Ротация/уровни, отсутствие диктовки и секретов в диагностическом логе по умолчанию | Логи доступны из tray; понятны пользователю и пригодны для поддержки |
| Tray/UI | Команды меню вызывают ожидаемые действия | Показ настроек/истории, выключение и выход не оставляют процесс или hotkey |
| Installer | Проверяется состав артефакта и корректность путей | Установка/удаление на чистой Windows, ярлык/автозапуск (если заявлен), нет прав администратора без необходимости |

## Негативные сценарии

1. Модель отсутствует, повреждена или её загрузка недоступна.
2. Нет микрофона, устройство занято, доступ запрещён политикой Windows.
3. Hotkey уже используется другой программой.
4. Пользователь отпускает hotkey до инициализации аудио либо несколько раз быстро нажимает её.
5. Активное окно сменилось за время распознавания; активного текстового поля нет.
6. Диктовка пустая, содержит Unicode/emoji, занимает много времени или Whisper завершился ошибкой.
7. Перезапуск приложения с повреждёнными history/settings/log-файлами.
8. Повторная установка/удаление и запуск без сети после установки.

## Автоматизация до релиза

- Unit: машина состояний диктовки, hotkey, конфигурация, storage истории, форматирование лога, адаптер вставки и ошибки Whisper.
- Integration (с подменами): `hold -> audio -> transcribe -> insert -> history`; отказ каждого внешнего адаптера не останавливает event-loop.
- Smoke: запуск упакованного `.exe` в изолированной папке, создание папки данных, проверка tray-процесса/корректного завершения.
- Installer smoke: silent install/uninstall на Windows VM; запуск установленного exe.
- Статический контроль: форматирование, линтер, type-check (если выбран стек), тесты с coverage для доменной логики.

## Решения о приватности

- Распознанный текст относится к персональным данным: по умолчанию не писать его в debug-логи.
- История должна иметь понятную кнопку удаления и предсказуемое место хранения в профиле пользователя.
- Локальная модель — единственный распознаватель; сетевые вызовы для транскрибации запрещены тестом/архитектурным контрактом.
