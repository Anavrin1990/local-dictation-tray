# Local Dictation Tray

Windows tray-приложение для диктовки в активное поле ввода. Удерживайте горячую клавишу, говорите, отпустите — запись локально расшифровывается через Whisper и вставляется в ранее активное приложение.

## Возможности

- глобальная удерживаемая комбинация (по умолчанию `ctrl+alt`);
- запись выбранного микрофона, локальный `faster-whisper` без облака;
- вставка через буфер обмена с сохранением прежнего содержимого;
- история расшифровок в SQLite и ротируемый журнал;
- настройки модели, языка, устройства и горячей клавиши;
- автозапуск вместе с Windows, включённый по умолчанию в установщике;
- плавающее окно возле указателя с предварительным текстом во время записи;
- финальная повторная расшифровка всей записи для уточнения слов и пунктуации;
- модель Whisper `small` уже входит в установщик: после установки интернет не нужен.

## Запуск для разработки

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python -m pip install -r requirements.txt
.\.venv\Scripts\python -m dictation_tray
.\.venv\Scripts\python -m unittest discover -s tests -v
```

Для Windows рекомендуется Python 3.11–3.12: на них доступны стабильные колёса PySide6, аудио и `ctranslate2`.

## Использование

1. Запустите приложение; значок появится в системном трее.
2. Поместите курсор в любое поле ввода.
3. Удерживайте `Ctrl+Alt`, произнесите фразу и отпустите клавиши.
4. Дождитесь уведомления — текст вставится в исходное поле.

Во время записи окно возле указателя показывает предварительный текст. После
отпускания клавиш приложение повторно расшифровывает запись целиком, вставляет
финальную версию и скрывает окно. В настройках доступны максимальные размеры,
положение и смещения окна, цвета текста и подложки, а также её прозрачность.

Модель `small` включается в установщик. На NVIDIA GPU она использует CUDA, а на обычном компьютере безопасно работает на CPU. После установки работа полностью офлайн: программа не скачивает модель и не отправляет аудио в сеть.

## Данные

Данные хранятся только локально в `%APPDATA%\LocalDictationTray`: `config.json`, `history.sqlite3`, `logs\app.log` и временные WAV. Записанный звук удаляется после успешной обработки; в историю попадает текст.

## Если что-то не работает

- **Микрофон не открывается.** Разрешите доступ для классических приложений в «Параметры Windows → Конфиденциальность и безопасность → Микрофон», затем выберите устройство в «Настройках» значка в трее.
- **Горячая клавиша не срабатывает.** Выберите другую комбинацию в настройках. Windows не передаёт глобальные нажатия в окно, запущенное с более высокими правами (например, от имени администратора); в таком случае запустите диктовку с теми же правами.
- **Модель не найдена.** Переустановите приложение полным установщиком. В журнале из меню трея будет точная техническая причина. Текст диктовки в журнал не записывается.
- **Вставка не туда.** Не открывайте другое окно во время расшифровки: приложение запоминает исходное окно и пытается вернуть ему фокус, но Windows может запретить принудительную смену фокуса.

## GPU и модель small

Установщик включает локальную `faster-whisper-small`: после установки модель и аудио не передаются в сеть. При запуске приложение проверяет NVIDIA GPU и выбирает GPU либо CPU; фактический режим виден в меню трея и настройках. В настройках можно вручную выбрать GPU NVIDIA или CPU. Ошибка GPU при загрузке или распознавании автоматически переключает приложение на CPU `int8` и записывает причину в журнал. GPU использует CUDA `float16`.

Модель можно выгружать из памяти сразу после распознавания или после 5, 10 либо 30 минут простоя. Немедленная выгрузка включена по умолчанию: приложение удаляет модель, запускает сборку мусора и просит Windows вернуть неиспользуемую физическую память. Подготовка модели начинается сразу при удержании горячих клавиш, чтобы предварительный текст мог появиться уже при первой диктовке.

Для диагностики готовой сборки: `LocalDictationTray.exe --gpu-self-check`. Команда выполняет короткий реальный запуск bundled small и печатает JSON; на машине с NVIDIA завершится ошибкой, если фактически не удалось использовать CUDA.
