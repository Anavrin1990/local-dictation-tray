# Local Dictation Tray

Windows tray-приложение для диктовки в активное поле ввода. Удерживайте горячую клавишу, говорите, отпустите — запись локально расшифровывается через Whisper и вставляется в ранее активное приложение.

## Возможности

- глобальная удерживаемая комбинация (по умолчанию `ctrl+alt+space`);
- запись выбранного микрофона, локальный `faster-whisper` без облака;
- вставка через буфер обмена с сохранением прежнего содержимого;
- история расшифровок в SQLite и ротируемый журнал;
- настройки модели, языка, устройства и горячей клавиши;
- первый запуск скачивает выбранную модель Whisper автоматически.

## Запуск для разработки

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python -m pip install -r requirements.txt
.\.venv\Scripts\python -m dictation_tray
.\.venv\Scripts\python -m unittest discover -s tests -v
```

Для Windows рекомендуется Python 3.11–3.12: на них доступны стабильные колёса PySide6, аудио и `ctranslate2`.

## Использование

1. Запустите приложение; значок появится в системном трее.
2. Поместите курсор в любое поле ввода.
3. Удерживайте `Ctrl+Alt+Space`, произнесите фразу и отпустите клавиши.
4. Дождитесь уведомления — текст вставится в исходное поле.

Модель `base` включается в установщик и подходит большинству CPU. После установки работа полностью офлайн: программа не скачивает модель и не отправляет аудио в сеть.

## Данные

Данные хранятся только локально в `%APPDATA%\LocalDictationTray`: `config.json`, `history.sqlite3`, `logs\app.log` и временные WAV. Записанный звук удаляется после успешной обработки; в историю попадает текст.

## Если что-то не работает

- **Микрофон не открывается.** Разрешите доступ для классических приложений в «Параметры Windows → Конфиденциальность и безопасность → Микрофон», затем выберите устройство в «Настройках» значка в трее.
- **Горячая клавиша не срабатывает.** Выберите другую комбинацию в настройках. Windows не передаёт глобальные нажатия в окно, запущенное с более высокими правами (например, от имени администратора); в таком случае запустите диктовку с теми же правами.
- **Модель не найдена.** Переустановите приложение полным установщиком. В журнале из меню трея будет точная техническая причина. Текст диктовки в журнал не записывается.
- **Вставка не туда.** Не открывайте другое окно во время расшифровки: приложение запоминает исходное окно и пытается вернуть ему фокус, но Windows может запретить принудительную смену фокуса.
